# Orbis Homelab 0.3.2

A clearer message when the app cannot reach the server.

## Changed

- **Network hint when the server is unreachable.** The "unreachable" banner and the "Can't start the app" screen now add a hint. When the app is opened from a Tailscale address (a `*.ts.net` name or an address in `100.64.0.0/10`) it asks whether Tailscale is on for this device; otherwise it suggests checking that the device is on the home network or VPN that reaches the server. The hint is worked out from the page address only: nothing is probed. See [Troubleshooting](../troubleshooting.md#orbis-non-raggiungibile-banner-on-a-phone).

## Upgrading from 0.3.1

The configuration format and the extension API are unchanged. Follow [Update with Compose](../update.md#update-with-compose) with `VERSION=0.3.2`, then relaunch the installed app.

## Known limitations

- The `arm64` image is built and inspected but not executed by the project's tests.
- During `0.x` the configuration format and the extension API can change in a minor version; neither changes in this release.
- Extensions run in the backend process with its privileges: install only code you trust.
- One language per instance (`it` or `en`).
