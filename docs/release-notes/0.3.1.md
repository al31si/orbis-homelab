# Orbis Homelab 0.3.1

A fix for the app installed on the iPhone Home Screen.

## Fixed

- **Gap below the bottom bar in the iOS installed app.** iOS 26 can report the viewport of a Home Screen app about one status-bar height shorter than the screen, so the app stopped above the bottom edge and left a strip of background under the bottom bar. In iOS installed apps only, when the viewport is between 1 and 120px shorter than the screen, the app now takes the screen height. Browsers and other platforms are unchanged.

## Diagnostics

- **This device** shows two new rows: **Viewport** (the size the app sees and the screen size) and **Height correction** (the applied value, or None). Include them when reporting a layout problem on a phone ([Troubleshooting](../troubleshooting.md#bottom-gap-in-the-ios-installed-app)).

## Upgrading from 0.3.0

The configuration format and the extension API are unchanged. Follow [Update with Compose](../update.md#update-with-compose) with `VERSION=0.3.1`, then relaunch the installed app.

## Known limitations

- The `arm64` image is built and inspected but not executed by the project's tests.
- During `0.x` the configuration format and the extension API can change in a minor version; neither changes in this release.
- Extensions run in the backend process with its privileges: install only code you trust.
- One language per instance (`it` or `en`).
